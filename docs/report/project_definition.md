# Project Definition

## Provisional Project Title

Urban Bus Service Non-Compliance Prediction Using PySpark and Machine Learning

## Problem Statement

Bus services do not always operate according to their planned timetable. Delays and early arrivals can affect passengers, reduce service reliability and make scheduling difficult for transport operators.

Large amounts of timetable and operational transport data are available, but these records are not always used to predict which journeys are more likely to become unreliable. This project will investigate whether PySpark and machine-learning techniques can be used to classify bus journeys as compliant or non-compliant.

## Project Aim

The aim of this project is to develop and evaluate a PySpark-based predictive analytics system that identifies whether a bus journey is likely to operate within an acceptable timetable tolerance.

## Project Objectives

1. Collect suitable timetable and operational transport data.
2. Build a dataset containing at least 100,000 records.
3. Clean and process the data using PySpark.
4. Analyse reliability patterns by route, operator and time period.
5. Train and compare at least three machine-learning models.
6. Evaluate the models using classification and performance metrics.
7. Store processed results in a relational database.
8. Present the findings using charts, tables and an optional dashboard.

## Stakeholder

The main stakeholder is a bus operator or local transport authority.

The stakeholder could use the analysis to identify unreliable routes, high-risk operating periods and journeys that may require schedule adjustments.

## Research Question

How accurately can timetable, route, time and disruption-related features predict whether a bus journey operates within the accepted timetable tolerance?

## Proposed Target Variable

A journey will provisionally be classified as:

- Compliant: the journey operates within the accepted timetable tolerance.
- Non-compliant: the journey operates outside the accepted timetable tolerance.

The exact definition will be confirmed after inspecting the available dataset.

## Project Scope

The project will include:

- large-scale transport data processing;
- PySpark DataFrames and PySpark SQL;
- data cleaning and integration;
- exploratory data analysis;
- machine-learning classification;
- comparison of at least three models;
- database storage;
- Spark performance evidence;
- visualisations and reporting.

The project will not include a live national transport system or personal passenger information.
