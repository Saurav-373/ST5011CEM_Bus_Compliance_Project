# ST5011CEM Bus Compliance Project

## Project Title

Urban Bus Service Non-Compliance Prediction Using PySpark and Machine Learning

## Module

- Module Name: Big Data Programming Project
- Module Code: ST5011CEM
- Assessment Type: Individual Coursework

## Project Overview

This project develops a PySpark-based predictive analytics pipeline for analysing urban bus service reliability. The planned system will process large-scale transport data and classify bus journeys as timetable-compliant or non-compliant.

The project will include data ingestion, cleaning, exploratory analysis, feature engineering, machine-learning model comparison, database integration, visualisation, Spark optimisation and critical evaluation.
